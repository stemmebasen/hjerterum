### Visning af din deltagerliste, redigering, aflysning af begivenhed osv.

1.  Log ind via topmenuen
2.  Vælg ‘Kalender’ fra rullemenuen ‘Events’
3.  Klik på dit arrangement
4.  Vælg ‘Admin’ over dit begivenhedsbillede (opdater siden, hvis du ikke kan se ‘Admin’)
5.  Vælg ‘Dashboard’ for at se dine deltagere
6.  Herfra kan du også redigere alle aspekter af din begivenhed.
